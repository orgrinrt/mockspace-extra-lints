The shape of a provisional stamp on a registry row: the two fields it is written in, the routes that can make one, and how the question ticket it names is read out of it. The lint `a-provisional-stamp-is-not-a-ratification` holds rows to this shape and the canon tool reads stamps through it, so both read one shape. It has no dependencies, which lets the always-on lint and the workflow crates reach it alike.
